# Linux Command Execution Time Profiler

## About the Project
This project was developed for the OSSSP Hackathon, Section 13. It demonstrates Linux command execution timing and important operating system concepts using C.

## Objectives
- Measure Linux command execution time.
- Understand process creation and management.
- Demonstrate process creation using `fork()`.
- Execute commands using `exec()`.
- Manage child processes using `waitpid()`.
- Demonstrate signals and concurrent processes.

## Technologies Used
- C Programming
- Linux / Ubuntu
- GCC Compiler
- Git and GitHub

## How to Compile and Run
Run these commands in an Ubuntu terminal:

```bash
gcc code.c -o profiler
./profiler
```
